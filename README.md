# markus-ai-server

## Developers

Install the project with its development dependencies:

```console
$ uv sync
```

(or `pip install -e . --group dev` with pip 25.1+; `dev` is a dependency group, not an extra)

Install the pre-commit hooks:

```console
$ pre-commit install
```

Run the tests:

```console
$ uv run pytest
```
